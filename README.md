# gpu-notes
compilation of my notes on gpu performance engineering from various sources

primarily follows this guide by wafer:
[gpu-perf-engineering-resources](https://github.com/wafer-ai/gpu-perf-engineering-resources#fundamentals)

although others are used as well 

note-taking methodology:
1. write hand-written notes
2. review, fact-check, and rewrite canonical notes online
3. add to github

note that these notes are primarily a way for me to keep a backed-up and easily accessible version of my paper notes for reference. i hope they are helpful and understandable to anyone who reads, but they may not be a great summary of the material.
